# Userscript Collection

Một bộ sưu tập các userscript hữu ích được viết bằng JavaScript để tăng cường trải nghiệm trên các trang web khác nhau.

## 📋 Danh sách Userscript

### 1. **Bypass Page Visibility** (`Bypass Page Visibility .js`)
Script này cho phép bạn bypass các hạn chế về visibility của trang missj*v (ví dụ: khi tab không được focus). Hữu ích cho các trang web có chức năng pause khi tab mất focus.

**Kích thước:** ~1.7 KB

### 2. **MPV Drag Handler** (`MPV Drag Handler.js`)
Cải thiện chức năng kéo thả (drag & drop) cho các phần tử trên trang. Hữu ích khi làm việc với media player hoặc các ứng dụng có hỗ trợ drag & drop.

**Kích thước:** ~3.9 KB

### 3. **NimoTV Chat Enhancer** (`NimoTV Chat Enhancer.js`)
Nâng cấp trải nghiệm chat trên NimoTV với các tính năng bổ sung như định dạng văn bản, emoji improvements, hoặc tối ưu hóa hiển thị chat.

**Kích thước:** ~4.7 KB

### 4. **NimoTV Super Auto-Refresh** (`NimoTV Super Auto-Refresh.js`)
Script tự động làm mới trang NimoTV theo khoảng thời gian định sẵn. Hữu ích để cập nhật nội dung mà không cần làm mới thủ công.

**Kích thước:** ~3.6 KB

### 5. **VOZ Custom Navigation** (`VOZ Custom Navigation.js`)
Tùy chỉnh thanh điều hướng trên VOZ (Việt Online Zone) hoặc các trang tương tự, giúp truy cập nhanh hơn đến các mục yêu thích.

**Kích thước:** ~2.5 KB

## 🚀 Cách sử dụng

### Yêu cầu
- Trình duyệt có cài đặt **Tampermonkey** hoặc **Greasemonkey** (hoặc các userscript manager khác)

### Hướng dẫn cài đặt

1. **Cài đặt Userscript Manager:**
   - Tải [Tampermonkey](https://www.tampermonkey.net/) cho trình duyệt của bạn
   - Hoặc [Greasemonkey](https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/) nếu bạn dùng Firefox

2. **Thêm script:**
   - Mở file `.js` từ repository này
   - Copy toàn bộ nội dung code
   - Tạo script mới trong Tampermonkey/Greasemonkey
   - Paste nội dung vào và lưu

3. **Hoặc cài đặt trực tiếp (nếu có @grant install):**
   - Nhấp vào file `.js` trong repository
   - Nhấp nút "Raw"
   - Sẽ hiển thị dialog cài đặt từ userscript manager
